# Template Examples

These files are concrete MDX structure references for the journal skill.

Load only the matching file after classification:

```text
references/template-examples/{family}/{subtype}.mdx
```

Use the example for:

- field structure
- component choice
- expert calibration
- quality checks
- action/risk/decision/evidence layout

Do not copy literally:

- frontmatter tags
- frontmatter summary
- frontmatter sources
- sample raw source paths
- placeholder wording that does not match the user's material

When generating a note, replace all placeholders with source-grounded content and follow `references/writing-rules.md`.
