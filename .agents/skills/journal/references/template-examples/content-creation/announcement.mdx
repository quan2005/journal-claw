# 公告

<Section density="relaxed">
  <Subtitle>公告的重点是减少不确定性：谁受影响、什么时候发生、用户要做什么、哪里能获得帮助，比宣传语更重要。</Subtitle>

<Callout type="tip" title="专业校准">
  变更沟通负责人的不确定性管理视角：公告的重点是减少不确定性：谁受影响、什么时候发生、用户要做什么、哪里能获得帮助，比宣传语更重要。
</Callout>

<Callout type="note" title="核心信息">
  【写清这份内容要让读者记住什么，以及读者为什么现在需要知道。】
</Callout>
