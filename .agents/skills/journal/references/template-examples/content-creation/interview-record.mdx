# 采访记录

<Section density="relaxed">
  <Subtitle>采访记录要保留原话的可追溯性，同时提炼可发布主题；不能把受访者没说过的话润色成结论。</Subtitle>

<Callout type="tip" title="专业校准">
  深度采访编辑的可追溯原话视角：采访记录要保留原话的可追溯性，同时提炼可发布主题；不能把受访者没说过的话润色成结论。
</Callout>

<Callout type="note" title="核心信息">
  【写清这份内容要让读者记住什么，以及读者为什么现在需要知道。】
</Callout>
