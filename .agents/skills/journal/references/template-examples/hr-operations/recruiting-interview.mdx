# 招聘面试记录

<Section density="relaxed">
  <Subtitle>用于面试记录：记录候选人背景、证据、风险、判断和后续动作。</Subtitle>

<Callout type="tip" title="专业校准">
  结构化招聘专家的胜任力证据视角：面试记录的价值不是印象总结，而是把岗位胜任力、行为证据、录用风险和后续验证动作绑在一起。
</Callout>
