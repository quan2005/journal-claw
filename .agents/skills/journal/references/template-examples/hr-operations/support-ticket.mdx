# 支持工单

<Section density="relaxed">
  <Subtitle>工单的核心是可复现、可分级、可交接、可验证关闭，并且客户沟通不能断线。</Subtitle>

<Callout type="tip" title="专业校准">
  ITIL 支持运营负责人的可交接工单视角：工单的核心是可复现、可分级、可交接、可验证关闭，并且客户沟通不能断线。
</Callout>
