# 深度阅读笔记

<Section density="relaxed">
  <Subtitle>用于深度阅读：先复述核心论点，再写证据、理解、疑问和复习点。</Subtitle>

<Callout type="tip" title="专业校准">
  Mortimer Adler 的分析阅读视角：深度阅读不是摘录更多，而是能复述作者的问题、论证链和自己可迁移的判断。
</Callout>
