# 客户拜访记录

<Section density="relaxed">
  <Subtitle>用于客户拜访：保留客户背景、需求、反对意见、购买信号和跟进行动。</Subtitle>

<Callout type="tip" title="专业校准">
  Steve Blank 的客户发现视角：客户拜访记录不是销售纪要，而是用客户原话和行为信号验证问题、现有替代方案、购买意愿和下一步实验。
</Callout>
