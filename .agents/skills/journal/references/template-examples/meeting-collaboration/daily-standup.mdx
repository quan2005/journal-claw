# 每日站会记录

<Section density="relaxed">
  <Subtitle>用于站会：每个人只记录状态变化、阻塞和今天最重要的行动。</Subtitle>

<Callout type="tip" title="专业校准">
  Jeff Sutherland 的 Scrum 检视与调整视角：站会不是状态汇报会，而是围绕迭代目标检查承诺、暴露阻塞、调整当天最小推进。
</Callout>
