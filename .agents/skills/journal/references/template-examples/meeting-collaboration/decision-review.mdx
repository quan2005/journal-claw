# 决策评审纪要

<Section density="relaxed">
  <Subtitle>用于记录存在取舍的评审会：保留问题、不同立场、关键证据、转折点和最终决策。</Subtitle>

<Callout type="tip" title="专业校准">
  Annie Duke 的决策质量视角：好决策记录要把结果好坏和决策质量分开，保留选项、关键假设、反证、转折点和复盘条件。
</Callout>
