# 设计评审纪要

<Section density="relaxed">
  <Subtitle>用于设计评审：记录目标、反馈主题、互斥意见、组合方案和下一轮修改。</Subtitle>

<Callout type="tip" title="专业校准">
  Don Norman 的以用户任务为中心的设计评审视角：设计反馈不能停留在审美偏好，必须绑定用户任务、可用性证据、互斥意见和下一轮验证。
</Callout>
