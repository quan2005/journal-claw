# 事故复盘纪要

<Section density="relaxed">
  <Subtitle>事故复盘要把人为错误当作分析起点，而不是根因；记录系统条件、检测、缓解、恢复和防复发验证。</Subtitle>

<Callout type="tip" title="专业校准">
  Sidney Dekker 与 John Allspaw 的无责事故复盘视角：事故复盘要把人为错误当作分析起点，而不是根因；记录系统条件、检测、缓解、恢复和防复发验证。
</Callout>
