# 进展同步纪要

<Section density="relaxed">
  <Subtitle>用于多人同步进展：突出状态变化、阻塞、风险和下一步计划。</Subtitle>

<Callout type="tip" title="专业校准">
  Eliyahu Goldratt 的约束理论视角：进展同步的核心不是逐人报功劳，而是找出限制吞吐的约束，并明确下一次同步前可以验证的解除动作。
</Callout>
