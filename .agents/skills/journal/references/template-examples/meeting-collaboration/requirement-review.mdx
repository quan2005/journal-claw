# 需求评审纪要

<Section density="relaxed">
  <Subtitle>用于需求评审：把背景、验收标准、变更点、争议和结论放在同一页。</Subtitle>

<Callout type="tip" title="专业校准">
  Marty Cagan 的产品发现视角：需求评审不是功能清单确认，而是把用户问题、证据、验收行为、范围变更和风险假设放到同一页。
</Callout>
