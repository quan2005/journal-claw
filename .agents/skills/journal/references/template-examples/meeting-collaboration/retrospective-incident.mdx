# 事故/项目复盘会

<Section density="relaxed">
  <Subtitle>事故/项目混合复盘要先选复盘类型，再对比预期与实际，解释差距，并把修复动作拆成防复发或可复用两类。</Subtitle>

<Callout type="tip" title="专业校准">
  Gary Klein 的 After Action Review 视角：事故/项目混合复盘要先选复盘类型，再对比预期与实际，解释差距，并把修复动作拆成防复发或可复用两类。
</Callout>
