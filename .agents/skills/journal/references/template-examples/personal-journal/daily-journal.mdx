# 日记

<Section density="relaxed">
  <Subtitle>日记不是把一天写满，而是把发生了什么、我怎么感受、我当时如何解释、明天做一个什么小动作留成可复核记录。</Subtitle>

<Callout type="tip" title="专业校准">
  James Pennebaker + Daniel Kahneman 的可复核日记视角：日记不是把一天写满，而是把发生了什么、我怎么感受、我当时如何解释、明天做一个什么小动作留成可复核记录。
</Callout>
