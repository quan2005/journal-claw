# 决策日志

<Section density="relaxed">
  <Subtitle>用于个人决策：记录当时信息、判断、预期、风险和复盘时间。</Subtitle>

<Callout type="tip" title="专业校准">
  Annie Duke + Tetlock 的决策日志视角：好决策日志要保留当时知道什么、不知道什么、各选项取舍和未来如何复盘，避免事后聪明。
</Callout>
