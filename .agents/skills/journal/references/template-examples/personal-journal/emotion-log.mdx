# 情绪记录

<Section density="relaxed">
  <Subtitle>情绪记录不是分析自己，而是给状态贴上更精确的标签，并记录触发、身体信号、解释和可做动作。</Subtitle>

<Callout type="tip" title="专业校准">
  Lisa Feldman Barrett + James Gross 的情绪标注视角：情绪记录不是分析自己，而是给状态贴上更精确的标签，并记录触发、身体信号、解释和可做动作。
</Callout>
