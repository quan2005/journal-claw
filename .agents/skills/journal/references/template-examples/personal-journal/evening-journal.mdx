# 晚间日志

<Section density="relaxed">
  <Subtitle>晚间记录要避免只被最后一件事支配，先列事实，再写感受和解释，最后完成收尾。</Subtitle>

<Callout type="tip" title="专业校准">
  Donald Schon + Kahneman 的晚间复盘视角：晚间记录要避免只被最后一件事支配，先列事实，再写感受和解释，最后完成收尾。
</Callout>
