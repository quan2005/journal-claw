# 家庭事务记录

<Section density="relaxed">
  <Subtitle>家庭事务记录应把人、事实、责任、待确认和跟进分开，避免把解释写成对人的判断。</Subtitle>

<Callout type="tip" title="专业校准">
  Harvard Negotiation Project 的原则谈判视角：家庭事务记录应把人、事实、责任、待确认和跟进分开，避免把解释写成对人的判断。
</Callout>
