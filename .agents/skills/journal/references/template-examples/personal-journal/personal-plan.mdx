# 个人计划

<Section density="relaxed">
  <Subtitle>个人计划要从期望结果倒推约束、资源、时间块、风险和下一步，而不是堆愿望清单。</Subtitle>

<Callout type="tip" title="专业校准">
  David Allen + Peter Drucker 的结果优先规划视角：个人计划要从期望结果倒推约束、资源、时间块、风险和下一步，而不是堆愿望清单。
</Callout>
