# 变更日志

<Section density="relaxed">
  <Subtitle>变更日志是面向读者的影响账本，不是 commit log。</Subtitle>

<Callout type="tip" title="专业校准">
  Olivier Lacan 的 Keep a Changelog 视角：变更日志是面向读者的影响账本，不是 commit log。
</Callout>

<Callout type="note" title="项目结论">
  【写清项目目标、当前边界、最重要的验收口径。】
</Callout>
