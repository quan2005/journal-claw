# 产品需求文档

<Section density="relaxed">
  <Subtitle>用于产品需求文档：写清用户、场景、需求、验收标准和开放问题。</Subtitle>

<Callout type="tip" title="专业校准">
  Marty Cagan 的产品发现视角：PRD 应把用户问题、产品行为、风险和成功指标分开，而不是堆功能清单。
</Callout>

<Callout type="note" title="项目结论">
  【写清项目目标、当前边界、最重要的验收口径。】
</Callout>
