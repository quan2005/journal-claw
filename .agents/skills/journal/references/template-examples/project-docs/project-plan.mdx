# 项目计划

<Section density="relaxed">
  <Subtitle>用于项目启动计划：明确目标、范围、角色、里程碑、风险和验收标准。</Subtitle>

<Callout type="tip" title="专业校准">
  Andy Grove 的高产出管理视角：项目计划不是愿望列表，而是目标、边界、节奏、责任人与前置风险构成的执行系统。
</Callout>

<Callout type="note" title="项目结论">
  【写清项目目标、当前边界、最重要的验收口径。】
</Callout>
