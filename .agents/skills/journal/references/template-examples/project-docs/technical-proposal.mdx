# 技术方案

<Section density="relaxed">
  <Subtitle>技术方案应记录约束下的选择、备选项、后果、上线与回滚，不是架构说明散文。</Subtitle>

<Callout type="tip" title="专业校准">
  Michael Nygard 的 ADR 视角：技术方案应记录约束下的选择、备选项、后果、上线与回滚，不是架构说明散文。
</Callout>

<Callout type="note" title="项目结论">
  【写清项目目标、当前边界、最重要的验收口径。】
</Callout>
