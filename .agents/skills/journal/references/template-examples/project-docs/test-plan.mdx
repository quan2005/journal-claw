# 测试计划

<Section density="relaxed">
  <Subtitle>测试计划应说明要降低哪些风险、用什么环境和数据证明，而不是穷举用例。</Subtitle>

<Callout type="tip" title="专业校准">
  Cem Kaner 的情境驱动测试视角：测试计划应说明要降低哪些风险、用什么环境和数据证明，而不是穷举用例。
</Callout>

<Callout type="note" title="项目结论">
  【写清项目目标、当前边界、最重要的验收口径。】
</Callout>
