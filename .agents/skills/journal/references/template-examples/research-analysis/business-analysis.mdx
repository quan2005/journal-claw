# 商业分析

<Section density="relaxed">
  <Subtitle>商业分析不能只列收入成本；要判断这个模式为什么能持续、哪里会被竞争或执行成本击穿。</Subtitle>

<Callout type="tip" title="专业校准">
  Alex Osterwalder + Hamilton Helmer 的商业模式视角：商业分析不能只列收入成本；要判断这个模式为什么能持续、哪里会被竞争或执行成本击穿。
</Callout>
