# 数据分析

<Section density="relaxed">
  <Subtitle>数据分析模板要防止看见趋势就讲故事；必须先写数据范围、口径和异常处理。</Subtitle>

<Callout type="tip" title="专业校准">
  John Tukey + Edward Tufte 的数据解释视角：数据分析模板要防止看见趋势就讲故事；必须先写数据范围、口径和异常处理。
</Callout>

</Callout>
