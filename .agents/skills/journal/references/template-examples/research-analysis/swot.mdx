# SWOT 分析

<Section density="relaxed">
  <Subtitle>SWOT 不应是四格词库；每一格都要有证据，并收敛到战略判断和下一步行动。</Subtitle>

<Callout type="tip" title="专业校准">
  Richard Rumelt 的好战略视角：SWOT 不应是四格词库；每一格都要有证据，并收敛到战略判断和下一步行动。
</Callout>

</Callout>
