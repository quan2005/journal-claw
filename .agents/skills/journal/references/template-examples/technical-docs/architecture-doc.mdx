<Section density="relaxed">
  <Subtitle>架构文档要按读者层级组织：先说明系统边界和关系，再进入容器、组件、运行时和质量属性。</Subtitle>

<Callout type="tip" title="专业校准">
  Simon Brown 的 C4 模型视角：架构文档要按读者层级组织：先说明系统边界和关系，再进入容器、组件、运行时和质量属性。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
