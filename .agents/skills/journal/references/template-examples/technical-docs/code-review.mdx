# 代码评审记录

<Section density="relaxed">
  <Subtitle>代码评审记录应优先保存行为风险、接口契约和必须修改项，而不是逐行复述代码。</Subtitle>

<Callout type="tip" title="专业校准">
  Michaela Greiler 的有效代码评审视角：代码评审记录应优先保存行为风险、接口契约和必须修改项，而不是逐行复述代码。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
