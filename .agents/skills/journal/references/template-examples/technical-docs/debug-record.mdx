# 调试记录

<Section density="relaxed">
  <Subtitle>用于调试记录：保留现象、假设、验证命令、结果、根因和后续防复发动作。</Subtitle>

<Callout type="tip" title="专业校准">
  Charity Majors 的可观测性调试视角：调试记录要保存证据链，而不是只保存最终修复；未来读者需要复盘每个假设为何成立或被排除。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
