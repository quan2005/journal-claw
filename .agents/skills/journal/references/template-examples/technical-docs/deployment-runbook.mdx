# 部署 Runbook

<Section density="relaxed">
  <Subtitle>Runbook 要让值班人按步骤执行并判断是否继续、暂停或回滚；它不是部署过程的回忆录。</Subtitle>

<Callout type="tip" title="专业校准">
  Google SRE Workbook 的运营就绪视角：Runbook 要让值班人按步骤执行并判断是否继续、暂停或回滚；它不是部署过程的回忆录。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
