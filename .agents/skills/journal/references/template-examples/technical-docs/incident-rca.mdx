# 故障 RCA

<Section density="relaxed">
  <Subtitle>用于故障 RCA：记录影响、时间线、根因、修复、验证和预防措施。</Subtitle>

<Callout type="tip" title="专业校准">
  John Allspaw / Google SRE 的无责复盘视角：RCA 不是寻找单一罪魁祸首，而是重建系统如何允许事故发生，并把检测、缓解和预防动作落到可验证改进。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
