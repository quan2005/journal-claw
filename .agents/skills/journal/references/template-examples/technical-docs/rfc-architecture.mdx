# 架构 RFC

<Section density="relaxed">
  <Subtitle>架构类 RFC 要把系统边界、替代方案、兼容性和迁移代价写成可审议的长期决策。</Subtitle>

<Callout type="tip" title="专业校准">
  IETF RFC + 架构 ADR 的 durable agreement 视角：架构类 RFC 要把系统边界、替代方案、兼容性和迁移代价写成可审议的长期决策。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
