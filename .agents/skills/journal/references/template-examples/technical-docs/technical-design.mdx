# 技术设计

<Section density="relaxed">
  <Subtitle>技术设计不是一次性蓝图，而是把当前约束下的可逆选择、不可逆选择和演进路径写清楚。</Subtitle>

<Callout type="tip" title="专业校准">
  Martin Fowler 的演进式架构视角：技术设计不是一次性蓝图，而是把当前约束下的可逆选择、不可逆选择和演进路径写清楚。
</Callout>

<Callout type="warning" title="结论">
  【写清问题、根因或方案结论；同时保留未覆盖风险。】
</Callout>
