# 日报

<Section density="relaxed">
  <Subtitle>日报不是流水账，而是把今日承诺闭环、未闭环原因和明日最小行动放进同一个可信系统。</Subtitle>

<Callout type="tip" title="专业校准">
  David Allen 的 GTD 视角：日报不是流水账，而是把今日承诺闭环、未闭环原因和明日最小行动放进同一个可信系统。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
