# 月度/季度汇报

<Section density="relaxed">
  <Subtitle>通用周期汇报要先固定比较口径，再按月度或季度选择粒度，避免同一模板生成不可比较的叙述。</Subtitle>

<Callout type="tip" title="专业校准">
  Ram Charan 的执行节奏视角：通用周期汇报要先固定比较口径，再按月度或季度选择粒度，避免同一模板生成不可比较的叙述。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
