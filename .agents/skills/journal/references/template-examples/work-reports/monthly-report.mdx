# 月报

<Section density="relaxed">
  <Subtitle>月报应回答本月对目标贡献了什么、资源是否用在正确事项上、下月该停止或加码什么。</Subtitle>

<Callout type="tip" title="专业校准">
  Peter Drucker 的目标管理视角：月报应回答本月对目标贡献了什么、资源是否用在正确事项上、下月该停止或加码什么。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
