# 绩效复盘

<Section density="relaxed">
  <Subtitle>绩效复盘要把事实证据、业务影响、行为模式和成长动作分开，避免空泛评价。</Subtitle>

<Callout type="tip" title="专业校准">
  Kim Scott 的 Radical Candor 视角：绩效复盘要把事实证据、业务影响、行为模式和成长动作分开，避免空泛评价。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
