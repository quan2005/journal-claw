# 项目进展汇报

<Section density="relaxed">
  <Subtitle>项目进展不能只写百分比；必须写清里程碑是否真实完成、关键路径是否变化、依赖是否可控。</Subtitle>

<Callout type="tip" title="专业校准">
  Fred Brooks 的项目里程碑视角：项目进展不能只写百分比；必须写清里程碑是否真实完成、关键路径是否变化、依赖是否可控。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
