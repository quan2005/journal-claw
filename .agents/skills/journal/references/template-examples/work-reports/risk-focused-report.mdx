# 风险专项汇报

<Section density="relaxed">
  <Subtitle>风险专项汇报要区分概率、暴露、触发信号和残余风险，不能只列风险名称。</Subtitle>

<Callout type="tip" title="专业校准">
  Nassim Nicholas Taleb 的尾部风险视角：风险专项汇报要区分概率、暴露、触发信号和残余风险，不能只列风险名称。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
