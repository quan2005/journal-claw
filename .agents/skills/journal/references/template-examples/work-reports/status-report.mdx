# 状态汇报

<Section density="relaxed">
  <Subtitle>状态汇报的价值在于暴露系统约束：当前状态、上次状态、变化原因和解除约束所需支持必须连在一起。</Subtitle>

<Callout type="tip" title="专业校准">
  Eliyahu Goldratt 的约束理论视角：状态汇报的价值在于暴露系统约束：当前状态、上次状态、变化原因和解除约束所需支持必须连在一起。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
