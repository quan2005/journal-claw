# 周报

<Section density="relaxed">
  <Subtitle>用于周报：用结论先行总结成果、指标、风险和下周重点。</Subtitle>

<Callout type="tip" title="专业校准">
  Andy Grove 的高产出管理视角：周报要汇报产出和杠杆，不汇报忙碌；指标要同时体现结果指标和前置指标。
</Callout>

<Callout type="note" title="结论">
  【一句话写清本周期状态：完成了什么、最大风险是什么、下一步最重要的动作是什么。】
</Callout>
