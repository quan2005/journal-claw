# Personal Journal Templates

## Family Boundary

- Recognition signal: 个人事件、感受、习惯、目标、生活决定或家庭安排。
- Expected output: 留下克制、具体、可回看的个人记录和小步行动。
- Routing rule: 以材料要完成的工作为准，不按单个关键词分类；会议产出的独立规格文档只有在用户明确要求时才切换家族。

## Subtypes

### daily-journal

- Classification signal: 日记相关素材，且主要任务与标题一致。
- Expected output: 日记；留下克制、具体、可回看的个人记录和小步行动。
- Required information: 发生了什么、当时的感受、重要想法、意义、下一步。
- Recommended components: `Summary`（留下当天主线）、`Callout`（标记一个值得注意的事实）、`Checklist`（保留一个小行动）。
- Example: [日记](../template-examples/personal-journal/daily-journal.mdx)

### decision-journal

- Classification signal: 决策日志相关素材，且主要任务与标题一致。
- Expected output: 决策日志；留下克制、具体、可回看的个人记录和小步行动。
- Required information: 决策问题、已知事实、选项、判断标准、关键假设、情绪/压力信号、预期结果与概率、复盘触发条件。
- Recommended components: `ComparisonMatrix`（外化个人选择标准）、`DecisionRecord`（保存假设和决定）、`RelatedEntry`（链接未来复查记录）。
- Example: [决策日志](../template-examples/personal-journal/decision-journal.mdx)

### emotion-log

- Classification signal: 情绪记录相关素材，且主要任务与标题一致。
- Expected output: 情绪记录；留下克制、具体、可回看的个人记录和小步行动。
- Required information: 触发事件、身体信号、情绪、想法、需要、小行动。
- Recommended components: `Timeline`（分开事件与反应）、`InsightCard`（记录解释而非定论）、`Checklist`（选择一个调节动作）。
- Example: [情绪记录](../template-examples/personal-journal/emotion-log.mdx)

### family-affairs

- Classification signal: 家庭事务记录相关素材，且主要任务与标题一致。
- Expected output: 家庭事务记录；留下克制、具体、可回看的个人记录和小步行动。

- Recommended components: `Steps`（安排顺序）、`Checklist`（检查准备事项）、`Table`（记录时间、预算或责任）。
- Example: [家庭事务记录](../template-examples/personal-journal/family-affairs.mdx)

### goal-okr

- Classification signal: 个人目标 OKR相关素材，且主要任务与标题一致。
- Expected output: 个人目标 OKR；留下克制、具体、可回看的个人记录和小步行动。
- Required information: 目标、关键结果、领先指标、当前证据、信心依据、反目标、下一步行动、下次检查日期。
- Recommended components: `Metrics`（呈现 KR 进展）、`StatusBadge`（标记信心或状态）、`Table`（记录偏差与动作）。
- Example: [个人目标 OKR](../template-examples/personal-journal/goal-okr.mdx)

## Family Quality Rules

- 事实、判断、未知项和下一步必须可区分。
- 只有真实存在的来源、负责人、日期和数字才能写成确定信息。
- Markdown 能表达清楚时不要强行使用组件。
