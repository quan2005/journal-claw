# Changelog

## [0.17.0](https://github.com/quan2005/journal-claw/compare/v0.16.0...v0.17.0) (2026-08-01)


### ⚠ BREAKING CHANGES

* rework composer-multi-model to one-credential-many-models, fix folder-no-icon alignment
* rebrand product runtime off Claude Code (.claude→.agent, CLAUDE.md→AGENTS.md)
* remove external CLI Coding Agent engine support, keep builtin only
* 仓库结构从单包改为 monorepo
    - src/ → apps/web/src/，src-tauri/ → apps/web/src-tauri/，scripts/ → apps/web/scripts/
    - 包管理 npm → pnpm（package-lock.json 删除，改 pnpm-lock.yaml）
    - CI/release 全部改 pnpm 命令 + apps/web 路径
    - 前端依赖继承到 apps/web/package.json，新增 @journal/contracts workspace 依赖
* 推翻已 verified spec 的字体决策，加载 Playfair Display + JetBrains Mono + Noto Serif SC 三个 web font；--font-mono 从 IBM Plex Mono 改为 JetBrains Mono；暖白分层取代原中性灰 #FAFAFA/#F4F4F5。
* 全局视觉契约变更——所有经 var(--record-btn) 等 令牌引用的组件自动跟随，但 inline-hex 文件需手工迁移（已处理）。
