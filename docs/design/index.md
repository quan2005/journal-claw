# 设计系统

谨迹的视觉系统建立在一个核心原则上：**克制的精致**。每一个像素都要证明自己的存在。

## 设计哲学

谨迹面向整日开会的知识工作者——他们需要的不是另一个争夺注意力的生产力工具，而是一个**退入背景、让内容呼吸**的安静空间。

在大多数生产力应用用色彩、动画、装饰争夺关注的时代，谨迹选择了相反的方向——它向后退，不向前抢。

## 墨水青中性体系

所有中性灰色都带有微妙的冷青色偏。用理性光谱的数据来说是介于"暖灰"和"冷灰"之间精确的中段——像档案墨水在优质纸张上自然褪色的质感。

浅色主题的底色 `#f5f6f7` 是近白却不刺眼——刚好偏离纯白，肉眼几乎无法察觉这是个颜色选择，这正是它的价值所在。

深色主题的底色 `#0f0f0f` 是近黑却不死板——比纯黑暖一度，比炭灰冷一度，带着同样的墨水调性。

**这是谨迹的个性**——不喧哗，不需要，恰好。

## 琥珀金 — 唯一的彩色

琥珀金（`#B8782A` 浅色 / `#C8933B` 深色）——陈旧黄铜、档案墨水、优质皮革的颜色。它在谨迹中扮演唯一的强调色角色：

- 录音按钮
- 选中条目（左边框 + 底色）
- 活跃状态
- AI 状态标记
- 深色模式下的 Markdown 标题
- 快捷键提示框

## 录音红 — 唯一的例外

录音红（`#ff3b30` / `#ff375f`）**仅**在麦克风激活录制时出现。这是一个语义精确的选择：琥珀金是交互色，录音红是状态色。它们的职能不重叠。

## 交互纪律

- 动画只能用 `transform` + `opacity`，不能动 `width`、`height`、`margin`、`padding`
- 缓动 `cubic-bezier(0.16, 1, 0.3, 1)`（ease-out-quart），没有回弹弹性
- 过渡 ≤ 300ms
- `prefers-reduced-motion` 降级为瞬间切换

## 层次主义

谨迹不使用卡片阴影。层次来自背景色的微妙递减：

```
--bg        → --sidebar-bg  → --dock-bg  → --titlebar-bg
#f5f6f7     → #f0f2f3       → #f0f2f3    → #edf0f1
```

每一层只有 2-5 个十六进制值的偏移。大脑感知到层次，但说不出为什么——这是最好的层次。

选中的条目用琥珀左边界（2-3px 竖线）作为活跃标识——不靠背景装饰。

## 十个不用

- 纯黑 `#000` 或纯白 `#fff`
- 暖调灰（米色系）— 中性是墨水青
- 卡片阴影和卡片嵌套
- 弹跳弹性缓动
- 毛玻璃、渐变、发光
- 400 以下或 600 以上的字重
- 浅色下给 Markdown 标题上色
- `width`/`height`/`margin`/`padding` 过渡
- 过大圆角（最大 12px）
- IBM Plex Mono 用于代码块之外
