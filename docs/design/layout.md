# 布局与间距

## 应用布局

两侧分割面板：可拖拽调整宽度的左侧列表 + 右侧详情 + 底部 Command Dock。

- **左侧面板** — 知识点条目列表，按月分组
- **右侧面板** — 选中条目详情，Markdown 渲染
- **底部 Dock** — 录音按钮、文件拖放区、粘贴区
- **标题栏** — `--titlebar-bg`，`[data-tauri-drag-region]` 区域

没有顶部导航栏——标题栏就是拖拽区，一切多余的结构被移除。

## 间距系统

4px 基准单位。节奏分为"紧凑"（组内）和"疏松"（组间）：

| Token | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 图标到文字间距、行内间距 |
| `--space-2` | 8px | 组件内部内边距 |
| `--space-3` | 12px | 列表项垂直内边距 |
| `--space-4` | 16px | Section 内部内边距 |
| `--space-6` | 24px | 相邻区块间距 |
| `--space-8` | 32px | Section 间距 |
| `--space-12` | 48px | 主区域分隔 |

## 信息密度原则

**左侧列表（密集）** — 14px 正文，12–13px 元信息，紧凑行距。目标：快速扫描。

**右侧详情（宽敞）** — 16px 正文，1.75 行高，段落宽松。目标：舒适阅读。

密集列表 vs 宽敞详情的对比是刻意的：扫描快，阅读松。

## 圆角尺度

| 值 | 用途 |
|---|---|
| 2px | 滚动条滑块 |
| 4px | 内联代码、小徽章 |
| 6px | 小型交互元素 |
| 8px | 标准容器、右键菜单、代码块 |
| 12px | 大型卡片、Sheet 把手 |

不使用 16px 以上的大圆角。这是工具界面，不是营销页面——圆角是功能性的，不是装饰。

## 层次与纵深

| 层级 | 处理 | 用途 |
|---|---|---|
| 平面 (0) | 无阴影、无边框 | 主背景、列表行 |
| 包容 (1) | `1px solid --divider` | 面板边框、Section 分隔 |
| 浮起 (2) | `--queue-shadow` | 处理队列、浮动元素 |
| 覆盖 (3) | `--context-menu-shadow` | 右键菜单、Sheet |

谨迹几乎不使用阴影。层次靠背景色的微妙阶梯——`--bg` → `--sidebar-bg` → `--dock-bg` → `--titlebar-bg`——每级偏移 2-5 个十六进制值。大脑感知到层次但说不出原因。

## 左侧边界标识

选中/高亮列表项的主要层次信号是一条 2-3px 的左侧竖线，颜色为 `--record-highlight-bar` / `--item-selected-bg` 搭配。这是谨迹的标识性交互模式——一条琥珀竖线说"这是当前活跃条目"，无需背景装饰。
