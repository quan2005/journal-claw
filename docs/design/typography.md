# 排版

## 字体栈

| 角色 | 字体 | 说明 |
|---|---|---|
| 正文 / UI | `system-ui, -apple-system, BlinkMacSystemFont, sans-serif` | SF Pro Text — 零加载成本 |
| 显示 | 同上 | 大字号自动激活 SF Pro Display |
| 等宽 | `'IBM Plex Mono', ui-monospace, monospace` | 仅用于代码块和内联代码 |
| 衬线 | `'Noto Serif SC', serif` | 已加载但极少使用，预留编辑时刻 |

SF Pro 是系统字体——不需要加载、不闪烁、不破坏系统 UI 一致感。刻意不引入自定义字体。

## 字号阶梯

| Token | 尺寸 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `--text-xs` | 12px | 400–500 | 1.4 | 时间戳、辅助信息 |
| `--text-sm` | 13px | 400–500 | 1.4 | 元信息、次要标签 |
| `--text-base` | 14px | 400–500 | 1.5 | 列表项正文、侧边栏文字 |
| `--text-md` | 16px | 400–500 | 1.75 | 详情面板正文、Markdown 段落 |
| `--text-lg` | 20px | 500–600 | 1.3 | 小标题、Section 标题 |
| `--text-xl` | 24px | 600 | 1.2 | 页面标题 |
| `--text-2xl` | 30px | 600 | 1.1 | 大标题（极少使用） |

## 字重角色

- **400** — 正文、元信息、次要标签
- **500** — 强调、活跃态、交互标签
- **600** — 标题、强烈强调

300 和 700+ 刻意排除。层次靠字号差异和 400→500→600 三级阶梯，不靠粗度两极。

## 信息密度分层

**左侧列表（密集）**：
- 14px 正文，单行截断
- 12–13px 元信息
- 行间紧凑
- 目标：快速扫描

**右侧详情（宽敞）**：
- 16px 正文，1.75 行高
- 段落宽裕
- 目标：舒适阅读

两者的反差是刻意的——扫描快，阅读松。不是 Bug，是设计。

## Markdown 排版

| 元素 | 浅色 | 深色 | 备注 |
|---|---|---|---|
| H1 | `#1c1c1e` | `#C8933B` | 深色下琥珀金，最大层级差 |
| H2 | `#2a3038` | `#C8933B` | 深色下同琥珀 — 标题即强调 |
| H3 | `#2a3038` | `#b0b4bc` | 稍微弱化 |
| 正文 | `#2a3038` | `#a8acb4` | 略比 UI 文字柔和 |
| 粗体 | `#1c1c1e` | `#C8933B` | 与 H1 同权 |
| 列表标记 | `#586068` | `#808488` | 退到内容后面 |
| 引用线 | `#c0c8ce` | `#48484a` | 结构线，非装饰 |
| 内联代码 | `#8A6500` | `#88b4e0` | 琥珀浅 / 蓝深 — 语义对比 |
| 链接 | `#8A6500` | `#6cb6ff` | 琥珀浅 / 蓝深 |

浅色模式下 Markdown 标题不用琥珀——琥珀标题是深色模式的专属特征。
