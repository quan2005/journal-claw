# 对话与 Agent

谨迹不仅是知识记录工具，更是知识对话伙伴。你可以向知识库提问，让它帮你发现洞察、梳理线索、回答疑问。

## 两种对话模式

### 聊天模式

适合快速查询和单轮问答：

- **提问** — "上周讨论的产品规划中哪些功能优先级最高？"
- **查询** — "找出所有涉及竞品分析的知识条目"
- **摘要** — "帮我总结这个月我关注的主要议题"

聊天模式以知识库中的条目为上下文，结合 AI 推理给出回答。响应以流式方式呈现，边思考边输出。

### Agent 模式

适合深度探索和复杂任务：

- **多步推理** — AI 自主决定需要检索哪些条目、从哪些角度分析
- **交叉关联** — "分析我最近三个月的会议记录，找出反复出现但未解决的话题"
- **动态探索** — AI 可能主动要求补充信息、打开相关文件、调用工具

Agent 模式利用内置 LLM 引擎的 **tool use（工具调用）** 能力，可以自主访问文件系统、搜索条目、读取画像，执行多轮操作。

## 对话上下文

对话以知识库为基础上下文：

- **当前条目** — 如果在左侧选中了一个条目，对话会以此为主要上下文
- **相邻条目** — 自动包含时间线上相邻的若干条目
- **相关画像** — 如果条目中引用了人物/项目/概念画像，对话会加载这些画像数据
- **关键词检索** — AI 依据你的问题自主检索知识库中相关条目

## 召唤专家视角

想让 AI 用某个专家的思考框架回应，而不是泛泛作答：

- 在输入框里输入 `@`，选择「专家」分类下的画像（画像需在 frontmatter 标注 `tags: ["专家"]` 或填写 `expert_skill`），发送后当轮及后续对话都会采用该专家视角
- 想切换或叠加视角，再 `@` 一个新专家；最近一次召唤的专家是主视角，更早召唤的作为参考
- 想回到默认视角，`@` 选择「清除专家视角」并发送，会移除当前会话已挂载的专家上下文
- 专家视角只对当前会话生效，新建会话不会继承

## 使用技巧

### 好的提问方式

- **具体而非笼统** — "这个月哪几次会议提到了预算问题？"比"有什么重要的事？"效果好
- **带时间范围** — "在过去两周里，关于产品A的讨论有什么进展？"
- **要求结论** — "总结一下张三在最近项目中提出的关键建议"
- **发现关联** — "我最近处理的几个项目之间有什么共同模式？"

### 对话管理

- 对话历史保存在会话中，可随时切换或新建
- Agent 模式的会话 ID 与聊天模式独立
- 支持 `Cmd+K` 清空当前对话，切换话题

## 上下文窗口

谨迹对每次对话的上下文做了约束：

- 默认包含最近若干条目的完整内容
- 超出窗口的旧条目，AI 通过关键词检索召回
- 如果答案不够精确，说明相关条目可能超出窗口——尝试缩小问题范围或指定具体日期
