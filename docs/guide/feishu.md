# 飞书桥接

飞书桥接让谨迹通过 WebSocket 连接飞书（Lark），实时接收消息并自动作为知识素材处理。你在飞书中收到的消息、文档、会议纪要，可自动汇入知识库。

## 工作原理

```
飞书客户端 / 服务端
  → WebSocket 推送消息到谨迹
  → daemon 飞书桥接服务接收
  → 消息按类型预处理（文本 / 文档 / 图片）
  → 提交到 AI 编译管线
  → 生成知识条目
```

## 配置飞书桥接

### 前提条件

- 飞书企业管理员权限（或获得授权）
- 飞书开放平台应用的 App ID 和 App Secret
- 谨迹版本 ≥ 0.11.0

### 配置步骤

1. 打开 **设置 → 飞书桥接**
2. 填入 App ID 和 App Secret
3. 配置事件订阅（接收哪些类型的消息）
4. 开启桥接开关
5. 谨迹开始通过 WebSocket 接收飞书消息

### 支持的消息类型

| 消息类型      | 处理方式               |
| ------------- | ---------------------- |
| 文本消息      | 直接作为文字素材提交   |
| 富文本 / 文档 | 提取纯文本后提交       |
| 图片          | AI 视觉分析后提交      |
| 文件          | 下载后作为文件素材提交 |

## 使用场景

### 移动端随手记

在飞书手机 App 中给自己发送想法、灵感、待办——消息自动汇入谨迹知识库。

### 飞书文档归档

将飞书中的重要文档分享给桥接 Bot，自动归档为知识条目。

### 团队会议纪要

飞书妙记 / 会议纪要通过桥接导入，由 AI 再处理和关联。

### 消息通知为素材

配置特定群组或联系人，他们的消息自动作为信息素材进入知识库。

## 隐私与安全

- WebSocket 连接使用加密传输
- App Secret 由本地配置服务安全保存
- 素材处理遵循与手动输入相同的隐私策略
- 可在设置中随时关闭桥接

## 故障排查

| 问题           | 可能原因             | 解决方案                     |
| -------------- | -------------------- | ---------------------------- |
| 连接失败       | App ID / Secret 错误 | 检查飞书开放平台应用凭据     |
| 收不到消息     | 事件订阅未配置       | 在飞书开放平台配置事件回调   |
| 消息未生成条目 | AI 引擎未配置        | 确认 AI 引擎已正确配置       |
| 连接频繁断开   | 网络不稳定           | WebSocket 自动重连，等待恢复 |
