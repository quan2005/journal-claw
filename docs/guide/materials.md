# 素材导入

除了语音录音，谨迹还支持两种"静默"输入方式：文件导入和文字粘贴。

## 文件导入

将文件拖入底部 Command Dock 的拖放区域，谨迹自动识别文件类型并提取内容。

### 支持的文件格式

| 格式 | 处理方式 | 说明 |
|---|---|---|
| PDF | 文本提取 + AI 摘要 | 正文、标题层级、元数据 |
| DOCX | 文本提取 + AI 摘要 | Microsoft Word 文档 |
| TXT | 直接读取 | 纯文本，保留原始内容 |
| Markdown | 直接读取 | 保留 Markdown 结构 |
| 图片 (PNG/JPG) | AI 视觉分析 | 通过 LLM 多模态能力提取信息 |

### 处理流程

1. 拖入文件 → Command Dock 显示文件名和类型
2. 谨迹提取文本内容（或对图片调用 AI 视觉分析）
3. AI 引擎生成结构化摘要
4. 原始文件保存到 `workspace/yyMM/raw/`
5. 新知识条目出现在时间线中

### 高级处理：PDF 和 DOCX

对于 PDF 和 DOCX，AI 会：

- 识别文档类型（会议纪要、技术方案、研究报告等）
- 提取关键信息和结论
- 生成描述性标题和标签
- 保留原文中的关键数据和引用

## 文字粘贴

适合快速记录：会议笔记、网页摘录、随机想法。

### 操作步骤

1. 点击底部 Command Dock 的粘贴区域（或使用快捷键 `Cmd+V`）
2. 粘贴文字
3. 可添加简短说明（可选）
4. 点击提交（或按 `Enter`）

### 适用场景

- **会议速记** — 开会时快速打字记录要点，会后再来回顾 AI 整理的结果
- **网页摘录** — 看到有价值的文章，复制核心段落扔进来
- **灵感捕捉** — 突然的想法，不用追求格式，只管写，AI 来整理
- **待办事项** — "明天要联系张三确认方案" → AI 自动识别并创建待办

## 与录音的配合使用

三种输入方式可以互补：

- **会议中** → 录音（全程语义，不打断思维）
- **会后** → 粘贴文字（补充关键决策、行动项）
- **相关文档** → 拖入文件（PPT、方案 PDF 等）

所有素材都会被 AI 关联到一起，形成完整的知识上下文。

## 素材溯源

无论哪种输入方式，每条知识条目都会保留与原始素材的关联：

- 条目旁的彩色来源标签可直接点击
- 点击后打开原始文件或查看原文
- 从知识条目追溯回原始素材，永不丢失上下文
