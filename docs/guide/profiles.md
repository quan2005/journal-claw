# 画像系统

画像（Identity Profiles）是谨迹的"认识论引擎"——你告诉谨迹"谁是谁"、"这是什么项目"、"这个概念怎么理解"，AI 就能在编译和对话中更精准地把握上下文。

## 三种画像类型

| 类型 | 用途                           | 示例                                     |
| ---- | ------------------------------ | ---------------------------------------- |
| 人物 | 同事、合作伙伴、客户           | "张三，产品经理，负责 A 产品线"          |
| 项目 | 工作项目、研究课题、任务       | "B 项目：2025 Q2 重点，目标提升日活 20%" |
| 概念 | 专业术语、行业概念、自定义定义 | "DAU：日活跃用户数，核心产品指标"        |

## 创建画像

在设置 → 画像中创建和管理画像：

1. 点击新建画像
2. 选择类型（人物 / 项目 / 概念）
3. 填写名称和描述
4. 可添加别名、关联关系、备注

描述越具体，AI 越能准确使用：

```
人物画像示例：
- 姓名：张三
- 角色：产品经理
- 背景：3年经验，负责 A 产品线和 B 项目
- 关联：与李四在 C 项目中合作

项目画像示例：
- 名称：A 产品线
- 目标：2025 Q2 提升日活 20%，降低流失率 5%
- 状态：进行中
- 关键人：张三（PM），李四（Tech Lead）

概念画像示例：
- 术语：NDA（净推荐值）
- 定义：用户推荐意愿的度量指标
- 计算方式：推荐者占比 - 贬损者占比
```

## 画像关联

画像与知识条目自动关联：

- 条目中出现画像名称或别名时，AI 自动建立关联
- 对话中提及相关人物或项目时，AI 加载对应画像作为上下文
- 条目详情中展示关联的画像标签

## 自动整理与画像

谨迹的[自动整理](/docs/guide/auto-lint)模块会定期检查画像健康：

- **孤立画像** — 长时间未被引用的画像，建议清理或更新
- **矛盾检测** — 不同条目中对同一画像的描述是否矛盾
- **概念抽取** — 从知识条目中识别高频术语，建议建立概念画像
- **信息补全** — 提示哪些画像缺少关键信息

## 使用场景

### 会议记录场景

为每个常开会的同事建立人物画像。AI 编译会议纪要、会议笔记或文字材料时，自动标记"张三提出"、"李四的反馈"。

### 项目跟踪场景

为每个项目建立项目画像。AI 会自动关联相关的会议、文档、决策到项目中，形成项目视角的知识图谱。

### 行业术语场景

为专业术语建立概念画像。AI 在编译时能正确理解行业黑话，不一知半解。
