# 快速上手

本文带你走完谨迹的核心操作流程。假设你已完成[安装与配置](/docs/guide/installation)。

## 界面概览

谨迹的界面由三个区域组成：

- **左侧列表** — 按月份分组的知识条目时间线
- **右侧详情** — 选中条目的完整内容（Markdown 渲染）
- **底部 Command Dock** — 文件拖放区、文字粘贴区

没有顶栏导航——标题栏本身就是拖拽区域，界面极尽克制。

## 两种输入方式

### 方式一：拖入文件

将 PDF、DOCX、TXT 文件直接拖入底部 Command Dock：

1. 谨迹提取文件内容
2. AI 分析并生成结构化摘要
3. 原始文件保存在 `workspace/yyMM/raw/` 下
4. 知识条目出现在时间线中，关联源文件

### 方式二：粘贴文字

1. 点击底部 Command Dock 的粘贴区域
2. 粘贴会议笔记、网页摘录、或任何文字
3. 点击提交
4. AI 编译为结构化知识条目

> **原则**：无论哪种方式，你只管"扔"，AI 负责"整理"。不要纠结于打字、排版、分类——这不是你要做的事。

## 查看与阅读

### 浏览时间线

左侧列表按月份分组显示所有知识条目：

- 每条条目显示标题、标签、摘要片段、来源图标
- 滚动自动加载更早的月份
- 点击条目，右侧详情面板展示完整 Markdown 内容

### 素材溯源

每个条目上的彩色标签（如 📄 文档、🤖 AI）是其来源。点击标签即可打开原始素材文件。

### 搜索

在搜索框中输入关键词，快速定位相关条目。

## 与知识库对话

切换到对话模式，向你的知识库提问：

- "上周讨论了哪些关于产品设计的议题？"
- "总结一下最近一个月关于竞品分析的内容"
- "我有哪些待办事项还没完成？"

谨迹会从你的知识条目中检索相关信息，结合 AI 能力给出回答。

对话支持两种模式：

- **聊天模式** — 单轮或多轮问答，适合快速查询
- **Agent 模式** — AI 自主分析你的知识库，适合深度探索
