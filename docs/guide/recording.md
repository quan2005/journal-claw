# 语音录音

语音录音是谨迹最核心的输入方式。一键开始，AI 接管后续所有处理。

## 操作流程

1. 点击底部 Command Dock 中央的琥珀色录音按钮
2. 说话——会议总结、灵感记录、任务备忘
3. 再次点击停止录音

谨迹自动执行以下处理管线：

```
原始音频采集（cpal + WAV）
  → 降噪（nnnoiseless）
  → 去静默 + 重采样（rubato）
  → 编码为 M4A（afconvert）
  → 语音转文字（STT 引擎）
  → AI 结构化编译
  → 写入知识条目
```

## 录音处理状态

| 状态 | 视觉表现 | 说明 |
|---|---|---|
| 待机 | 信号橙发送按钮 | 就绪，点击开始录音或发送素材 |
| 录制中 | AI 状态标识（橙色调） | 音频正在捕获 |
| 处理中 | AI 状态标识（橙色活跃态） | 音频正在转写和编译 |

信号橙 `#FF5701` 是谨迹唯一的交互 accent 色，覆盖录音、发送、选中、AI 状态等所有需要用户注意的场景。

## 语音引擎选择

在 **设置 → 语音引擎** 中选择：

### Apple 原生（推荐）

- **引擎**: macOS SFSpeechRecognizer / SpeechAnalyzer
- **要求**: macOS 12+，无需配置
- **特点**: 零延迟、离线可用、设备端处理，隐私最高
- **限制**: macOS 26+ 才有 SpeechAnalyzer（更高精度）

### WhisperKit

- **引擎**: Apple WhisperKit（本地离线）
- **要求**: 首次使用会自动下载模型（约 1.5 GB）
- **特点**: 精度极高，完全离线，支持更多语言
- **限制**: 下载量较大，首次使用需等待

### DashScope（云端）

- **引擎**: 阿里云百炼 DashScope
- **要求**: 需在 AI 引擎中配置阿里云 API Key
- **特点**: 精度最高，不受本地算力限制
- **限制**: 需要网络连接，有 API 调用成本

## 录音质量优化

- **安静环境** — 降噪算法能处理环境噪底，但近距离清晰的语音效果最好
- **正常语速** — 无需刻意放慢或加快
- **自然停顿** — 去静默算法依赖自然停顿来分割段落，不需要连续不断地说
- **距离适中** — 距离麦克风 20-40cm，和正常对 Mac 说话的距离一致
