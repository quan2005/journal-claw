# 设置面板

谨迹的设置面板包含 6 个配置区域。本文逐一说明每个区域的用途和选项。

## 通用

| 设置项 | 说明 |
|---|---|
| 工作区路径 | 知识库的存储位置。支持多工作区，按月自动归档 |
| 语言 | 界面语言（中文 / English） |
| 启动时打开 | 是否在登录时自动启动 |
| 菜单栏图标 | 是否在菜单栏显示谨迹图标 |

## AI 引擎

| 设置项 | 说明 |
|---|---|
| 提供商 | Anthropic / 火山方舟 / 智谱 AI / 阿里云百炼 |
| API Key | 提供商的 API 密钥，存储在 macOS Keychain |
| 模型 | 选用的具体模型（取决于提供商） |
| Endpoint ID | 火山方舟需要的额外字段 |
| 编译温度 | AI 编译时的 temperature 参数（推荐默认） |
| 对话温度 | 对话时的 temperature 参数 |

### 多厂商切换

切换 AI 提供商不会丢失数据。所有知识条目格式统一，仅编译和对话的模型不同。

## 外观

| 设置项 | 说明 |
|---|---|
| 主题 | 浅色 / 深色 / 跟随系统 |
| 强调色 | 信号橙 `#FF5701`（仅此一色） |
| 字体大小 | 预设紧凑 / 默认 / 宽松 |

## 自动整理

| 设置项 | 说明 |
|---|---|
| 启用 | 是否开启定时自动维护 |
| 间隔 | 每天 / 每周 / 每月 |
| 矛盾检测 | 是否检测条目间的信息矛盾 |
| 孤立画像清理 | 是否建议清理未使用的画像 |
| 概念抽取 | 是否自动建议新概念画像 |
| 信息补全 | 是否提示缺失的信息 |

## 飞书桥接

| 设置项 | 说明 |
|---|---|
| 启用 | 是否开启飞书 WebSocket 连接 |
| App ID | 飞书开放平台应用 ID |
| App Secret | 飞书应用密钥 |
| 消息类型 | 接收哪些类型的消息 |

详见[飞书桥接](/docs/guide/feishu)。
