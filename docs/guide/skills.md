# 技能插件

技能（Skills）是谨迹的插件系统——通过 `SKILL.md` 文件定义自定义处理流程，扩展 AI 的能力。

## 什么是技能

技能是一个 Markdown 文件，使用 YAML frontmatter 定义元数据，正文包含给 AI 的指令。当 AI 处理素材时，如果有匹配的技能，会按技能的指示进行处理。

```
技能 = 元数据（何时触发） + 指令（如何处理）
```

## 技能文件结构

```markdown
---
name: meeting-minutes
description: 会议纪要整理技能
triggers:
  - "会议"
  - "开会"
  - "纪要"
---
# 会议纪要整理

当素材包含会议内容时，请按以下格式整理：

1. 提取会议主题和时间
2. 列出参会人员
3. 按议题分组整理讨论要点
4. 提炼决策结论
5. 列出待办行动项
```

## 技能存放位置

技能文件可以放在两个位置：

| 位置 | 作用范围 | 说明 |
|---|---|---|
| `workspace/skills/` | 当前工作区 | 仅对该工作区生效 |
| `~/.claude/skills/` | 全局 | 对所有工作区生效 |

## 触发机制

技能的触发依赖于 frontmatter 中的 `triggers` 字段：

- AI 在处理素材时，检查素材内容是否匹配触发关键词
- 匹配到的技能会被加载为 AI 的额外指令
- 多个匹配的技能可以同时生效

### 触发条件

```yaml
triggers:
  - "会议"      # 简单关键词匹配
  - "面试|访谈"  # 正则表达式支持
```

## 自定义场景示例

### 日报整理技能

```yaml
triggers: ["日报", "每日", "today I worked on"]
```

指示 AI 按"做了什么 → 遇到什么问题 → 明日计划"三段整理。

### 代码审查技能

```yaml
triggers: ["code review", "PR", "代码审查"]
```

指示 AI 提取代码变更点、潜在问题、优化建议。

### 客户沟通记录

```yaml
triggers: ["客户", "client", "甲方"]
```

指示 AI 提取客户需求、承诺事项、下一步行动。

## 管理与调试

- 在设置 → 技能中查看已加载的技能列表
- 支持启用/禁用特定技能
- AI 处理失败时，可以查看是哪个技能的指令导致的问题
