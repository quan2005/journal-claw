# 声纹档案

声纹档案让谨迹在会议录音中识别不同的说话人。命名一次讲话者的声音，AI 之后用你起的名字标注——所有处理在设备端完成，不出 Mac。

## 工作原理

谨迹通过 Swift sidecar 组件调用 Apple 设备端说话人识别能力：

```
录音文件（M4A）
  → Swift sidecar 加载音频
  → 设备端声纹分割（说话人变化检测）
  → 声纹聚类（同一人的不同片段归到一起）
  → 与已命名的声纹档案匹配
  → 输出：说话人 A → 张三，说话人 B → 李四
```

全部处理离线，不需要网络，不发送任何数据到云端。

## 设置声纹档案

### 首次设置

1. 打开设置 → 声纹档案
2. 点击"新建声纹"
3. 选择一个包含该说话人音频的录音文件
4. 系统自动提取声纹特征
5. 为这个声音命名（如"张三"）
6. 可关联到已创建的人物画像

### 批量标注

如果你有多段会议录音：

1. 在设置中开启"自动识别"
2. 录制或导入会议音频
3. AI 编译时自动尝试匹配已知声纹
4. 未匹配到的说话人标记为"未知说话人 X"
5. 你可以在声纹档案中给"未知说话人 X"命名

## 与人物画像联动

声纹档案与[画像系统](/docs/guide/profiles)无缝联动：

- 为声纹命名后，可选择关联已有的人物画像
- 如果不存在对应画像，系统建议创建
- 关联后，AI 编译会议记录时会自动使用画像中的角色、背景等信息

## 隐私

声纹档案完全运行在设备端：

- 音频数据不离开 Mac
- 声纹特征加密存储在工作区中
- 你可以随时删除任一声纹档案

## 使用场景

### 多人会议

5 人周会，2 人主要发言。命名所有人的声纹后，AI 编译的会议纪要自动标注"张三提出"、"李四反馈"。

### 访谈记录

一对一深度访谈。命名受访者声纹后，AI 编译的访谈记录准确区分问题和回答。

### 用户研究

多场用户测试的录音。命名全部参与者声纹后，轻松对比不同用户的反馈。
