# 主题

谨迹的视觉系统建立在一个核心原则上：**克制的精致**。每一个像素都要证明自己的存在。

## 双主题

谨迹支持浅色和深色两种主题，默认跟随系统：

- **浅色主题** — 微微偏冷的近白底色 `#f5f6f7`，像高质量纸面在冷光工作室灯下的质感
- **深色主题** — 近黑底色 `#0f0f0f`，比纯黑更暖、比炭灰更冷，带同样的墨水调性

主题切换：设置 → 外观 → 浅色 / 深色 / 跟随系统。

## 墨水青中性体系

谨迹所有中性灰色都带有微妙的冷青色偏——肉眼几乎察觉不到，但大脑会感知。这不是"暖灰"也不是"冷灰"，而是精确的中间色域，像档案墨水自然褪色后的质感。

**这不是技术细节——这就是谨迹的个性。**

## 琥珀金强调色

谨迹只有一个彩色强调色：琥珀金（`#B8782A` 浅色 / `#C8933B` 深色）。它是陈旧的黄铜、档案墨水和优质皮革的颜色。

出现位置：
- 录音按钮（主要 CTA）
- 选中条目（左边框 + 底色）
- 活跃状态指示器
- AI 状态徽标
- Markdown 标题（深色模式下）
- 快捷键徽章

## 录音红

唯一破例的第二种彩色：录音红（`#ff3b30` / `#ff375f`），**仅**在麦克风活跃录制时出现。

琥珀金 = 品牌色 / 交互色。
录音红 = 紧急色 / 状态色。

两者语义不同，不冲突。

## 设计纪律

### 用
- CPU 合成的颜色变化（不触发 repaint）
- CSS 过渡：`transform` + `opacity`，≤ 300ms，`ease-out-quart`
- `prefers-reduced-motion` 降级
- 阴影极少——层次来自背景色的微妙阶梯，而非投影

### 不用
- 纯黑 `#000` 或纯白 `#fff`——用近黑 `#0f0f0f` 和近白 `#f5f6f7`
- 暖调灰——中性系统是墨水青，不是米色
- 卡片阴影和卡片嵌套——层次靠底色阶梯和左边界
- 弹跳弹性缓动——只用 ease-out-quart
- 毛玻璃、渐变、发光效果
- 400 以下或 600 以上的字重
- 浅色模式下给 Markdown 标题加彩色——琥珀标题是深色模式专属
