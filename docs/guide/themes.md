# 主题

谨迹的视觉系统建立在 **Modern · Bold · Agentic** 基调上：清晰的行动号召、明确的产出、对话式 AI 优先。完整设计规范见 [DESIGN.md](/DESIGN.md)。

## 双主题

谨迹支持浅色和深色两种主题，默认跟随系统：

- **浅色主题** — 纯白表面 `#FFFFFF`，配暖白分层 `#F6F6F1`/`#ECECE6`，像高质量纸面的温润质感
- **深色主题** — 近黑底色 `#0F0F0F`，配中性暗灰分层 `#1C1C1E`/`#2C2C2E`，对比锐利

主题切换：设置 → 外观 → 浅色 / 深色 / 跟随系统。

## 信号橙强调色

谨迹只有一个交互强调色：**信号橙**（`#FF5701` 浅色 / `#FF7A33` 深色提亮）。它是现代、大胆、对话式 AI 产品的标志色。

出现位置：
- 选中条目（橙软底 + 橙色文字 + 3px 橙竖条）
- 活跃的分段控件 / 筛选 tabs
- AI 状态标记
- 链接、复选框、聚焦环
- 橙填充按钮（文字用墨色保证对比度）

**单橙规则**：信号橙是有且仅有的唯一交互 accent。语义色（成功绿/警告黄/危险红/信息蓝）仅在状态徽章、callout、文件类型图标等语义场景出现，不作交互 accent。

## 表面分层

深度通过背景色阶差传达，而非投影：

- **表面**（`#FFFFFF` / `#0F0F0F`）：主应用背景
- **次表面**（`#F6F6F1` / `#1C1C1E`）：浮起表面——处理队列、代码块背景、卡片底色
- **三表面**（`#ECECE6` / `#2C2C2E`）：更深一层分隔

三档表面保持 ΔE≥3 的可感知分层。

## 字体三栈

- **标题**：Playfair Display（西文衬线，中文回退 Noto Serif SC）——承载 bold 气质的衬线个性
- **正文**：系统无衬线栈（macOS 上即 SF Pro）——零加载、完美系统集成
- **代码**：JetBrains Mono——代码与技术语义专用

三栈各司其职，不混用。

## 设计纪律

### 用
- 信号橙覆盖所有交互 accent 场景
- 表面分层（白 → 暖白 → 深暖白）传达深度，而非阴影
- 纯白 `#FFFFFF` 作主背景、墨色 `#111827` 作主文字
- 结构化 token（`--radius-*` / `--shadow-overlay` / `--border-menu` / `--focus-ring`）
- CSS 过渡：`transform` + `opacity`，≤ 300ms，`ease-out-quart`（循环动画豁免 `ease-in-out`）
- `prefers-reduced-motion` 降级
- 阴影仅用于浮层（菜单、对话框），且功能导向

### 不用
- 第二种彩色交互 accent——信号橙是唯一
- `#FF5701` 直接作小号正文文字色（对比度 2.7:1 不达标）——仅作填充背景
- 卡片阴影或卡片套卡片嵌套——层次来自表面分层
- 弹跳弹性缓动——非循环过渡仅 ease-out-quart
- 动画布局属性（`width`/`height`/`margin`/`padding`）——仅 `transform` + `opacity`
- 毛玻璃（`backdrop-filter`）、装饰性渐变、发光效果
- 渐变文字（`background-clip: text` 配渐变）
- 各自硬编码聚焦环——必须用 `--focus-ring` token
