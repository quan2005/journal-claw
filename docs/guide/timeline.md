# 时间线记忆

谨迹将你的所有知识条目沿时间线自动排列，形成持续积累的个人记忆体系。理解时间线的浏览、搜索、阅读方式，是高效使用谨迹的关键。

## 界面布局

时间线界面分为两个面板：

- **左侧列表** — 按月份分组的知识条目列表，信息密集，适合快速扫描
- **右侧详情** — 选中条目的完整 Markdown 渲染内容，舒适阅读

面板之间的分隔线可拖拽调整宽度。

## 列表浏览

### 信息密度设计

左侧列表刻意保持紧凑：

- 条目正文：14px，单行截断
- 元信息（日期、标签）：12-13px
- 行内间距紧凑，一个月可以容纳数十条条目
- 右侧详情面板则更宽敞——16px 正文，1.75 行高

**密集列表 + 宽敞详情** 的对比是刻意的：扫描时速度快，阅读时眼睛轻松。

### 月份分组

条目按 `YYYY年M月` 分组。月份标签使用低对比度文字，不争抢注意力。

### 分页加载

时间线默认加载最近数月。向下滚动到底部自动加载更早的月份。不会一次性加载全年条目，防止滚动性能下降。

## 条目视觉标识

每条条目在列表中的视觉信号：

| 元素     | 说明                                              |
| -------- | ------------------------------------------------- |
| 左侧色条 | 选中的条目有琥珀色左边界（2-3px），信号"当前活跃" |
| 来源图标 | 📄 文档 / 📝 文本 / 🤖 AI 等彩色标签              |
| 标签     | AI 提取的关键词标签，内联显示                     |

## 阅读体验

选中条目后，右侧详情面板展示完整的 Markdown 渲染内容：

- **标题层级** — H1/H2/H3 清晰区分
- **代码高亮** — highlight.js 着色，IBM Plex Mono 等宽字体
- **引用块** — 左侧灰色竖线标识引文
- **链接** — 可点击打开
- **来源标签** — 悬浮在标题旁，可点击追溯原始素材

### 沉浸阅读模式

专注阅读时，可将左侧列表收起，让详情面板占满全宽。

## 搜索

在搜索框中输入关键词，跨所有月份和时间线搜索条目：

- 搜索范围覆盖标题、标签、摘要、正文
- 搜索结果实时过滤左侧列表
- 结果按时间倒序排列

## 素材溯源

每条知识条目的来源标签可点击，打开对应的原始素材：

- **文档条目** → 打开原始 PDF/DOCX/TXT 文件
- **粘贴条目** → 查看原始粘贴文本
- **AI 总结条目** → 查看生成来源

## 右键操作

右键任何条目弹出上下文菜单：

- **@引用** — 将条目引用插入输入框
- **复制链接** — 复制条目路径
- **打开素材目录** — 在 Finder 中显示原始文件
