# 待办事项

谨迹不仅能记录过去，还能帮助你管理未来——它自动从你的知识条目中识别行动项，统一管理。

## AI 自动识别

当 AI 编译你的素材时，会主动识别其中包含的待办事项：

- "明天找张三确认一下方案时间节点"
- "这周需要完成竞品分析报告"
- "下周一之前回复李四的邮件"

这些行动项会被自动提取，并作为待办事项出现在侧边栏中。

## 手动创建

你也可以手动创建待办：

1. 在知识条目详情中选中一段文字
2. 右键 → 创建待办事项
3. 待办事项关联到当前条目（可溯源上下文）

## 待办管理

### 按路径分组

待办事项按工作区路径分组——不同月份 / 项目的待办自动分类，避免混杂。

### 截止日期

- 支持设置截止日期
- 逾期未完成的待办带有视觉提醒
- 可在设置中调整提醒策略

### 关联会话

待办事项可以关联到对话会话。在 Agent 模式中讨论了某个问题并产生了待办，关联关系会被保留，方便回溯讨论上下文。

## "深入探索"

右键待办事项，选择"深入探索"（Explore in Depth）：

- 开启一个 Agent 会话
- AI 以该待办事项为核心，分析相关的知识条目和画像
- 帮助你理清需要哪些准备、关联哪些人、参考什么历史决策

## 待办与知识条目

待办事项和知识条目是双向关联的：

- 从待办可以跳转到对应的知识条目，了解完整上下文
- 从知识条目可以看到关联的待办列表
- 完成待办后，条目中会记录完成时间
