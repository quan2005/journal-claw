# 对齐记录模板（对齐会 / 碰头会）

**适用场景**：2-4 人小范围的需求对齐或方案碰撞。

**核心价值**：记录"对齐了什么、没对齐什么"。不光要记已达成的共识，没达成的分歧更关键 — 它们是下一步推进的发力点。

**视觉增强**：已对齐/未对齐事项可使用 `.pros-cons` 组件，参会人可使用 `.cards` 网格展示。

## 结构

```html
<h2>背景</h2>
<p>一句话说明这次对齐的目的和触发原因。</p>

<h2>参会人</h2>
<p>列出参会人及其角色 / 立场。</p>

<h2>已对齐事项</h2>
<p>按议题分节，每个议题：</p>
<ul>
  <li><strong>结论</strong>：一句话</li>
  <li><strong>关键依据</strong>：为什么这么决定（如有争论，简要记录）</li>
  <li><strong>负责人</strong>：谁来执行</li>
</ul>

<h2>未对齐事项</h2>
<p>明确列出哪些问题没有达成共识：</p>
<ul>
  <li><strong>分歧点</strong>：各方的不同看法</li>
  <li><strong>下一步</strong>：如何推进（再开会？找谁拍板？先试点验证？）</li>
</ul>

<h2>待办</h2>
```

## 对齐记录的关键原则

- **"未对齐"比"已对齐"更重要** — 已对齐的事项执行就好，未对齐的才需要持续关注
- **记录每个结论的依据，哪怕只有一句话** — 避免后续有人说"当时没说过这个"
