# 进度追踪模板（周会 / 进度同步会）

**适用场景**：多人轮流汇报、逐条过进展的会议。

**核心价值**：快速提取状态变化和风险信号。读者关心的不是"此刻的状态"，而是"从上次到现在发生了什么"。

**视觉增强**：风险看板可使用 `.cards` 网格（每项风险一张卡片），待办清单保持 `<table>`，关键讨论可使用 `.option` 组件。

## 结构

```html
<h2>一、进展汇总</h2>
<p>按汇报人或项目线分节，每条用统一格式：</p>

<h3>项目 / 商机名称</h3>
<ul>
  <li><strong>状态</strong>：进行中 / 已完成 / 阻塞 / 关闭</li>
  <li><strong>本周进展</strong>：一句话概括</li>
  <li><strong>风险 / 阻塞</strong>：如有</li>
  <li><strong>下一步</strong>：具体动作 + 负责人 + 时间</li>
</ul>

<h2>二、关键讨论</h2>
<p>如果周会中出现了超出进度汇报的讨论（方向性决策、资源争夺等），
单独提出来，按论证链模板的简化版记录：
争议焦点 → 结论 → 负责人。</p>

<h2>三、待办清单</h2>
<p>从全文提取所有待办，汇总为一张表：</p>

<table>
  <tr><th>待办事项</th><th>负责人</th><th>截止时间</th><th>来源议题</th></tr>
  <tr><td>...</td><td>...</td><td>...</td><td>...</td></tr>
</table>

<h2>四、风险看板</h2>
<p>提取所有被提及的风险和阻塞项：</p>

<table>
  <tr><th>风险项</th><th>严重度</th><th>影响范围</th><th>当前应对</th></tr>
  <tr><td>...</td><td>...</td><td>...</td><td>...</td></tr>
</table>
```

## 进度追踪的关键原则

- **状态变化比状态本身重要** — "从 60% 推进到 80%" 比 "目前 80%" 有信息量
- **数字要保留** — 金额、百分比、人数、日期，这些是周会纪要的骨架
- **商机类周会特别注意保留**：商机阶段变化、客户关键反馈、竞争对手动态
