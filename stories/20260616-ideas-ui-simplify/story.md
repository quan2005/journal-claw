# 简化想法工作台 UI

## 背景

当前 `IdeasWorkbench` 组件包含筛选标签栏（4 个 tab）、统计摘要栏（3 列数字）、"新建想法"按钮，以及顶部出现的 textarea 草稿区。用户希望精简为更轻量的单一视图，减少视觉噪音，让列表和输入成为唯一焦点。

[证据] `src/components/IdeasWorkbench.tsx` L137–188（tabs 定义与渲染）；L154–174（stats + 按钮）；L192–218（drafting textarea）

## 目标

让想法工作台回归"快速捕捉 + 浏览"的核心体验：去掉不常用的筛选和统计，把输入区固定在底部、随时可见。

## 验收标准

- **AC-1** 当用户打开想法工作台，不再看到筛选标签栏（全部/待探讨/有截止日期/已完成）、统计摘要栏、"新建想法"按钮。
- **AC-2** 当用户打开想法工作台，描述文字（intro）不受 max-width 限制，跟随容器全宽展示。
- **AC-3** 当用户打开想法工作台，列表默认展示所有未完成项（等同现有 `filter === 'all'`），无需手动筛选。
- **AC-4** 当用户查看想法工作台底部，看到一个常驻的多行 textarea 输入框 + 右侧加号提交按钮；按 Enter 即可提交新想法。
- **AC-5** 当用户在输入框中输入文字，文字颜色为普通前景色（不带 accent 高亮），光标颜色跟随前景色。
- **AC-6** 当用户聚焦输入框，textarea 边框不产生高亮变化（无 focus ring / border-color 变化）。

## 非目标

- 不改变已完成项的数据存储或查询逻辑（只是不展示 tab 入口）
- 不引入 toast 撤销、行内删除按钮等 mockup 中的其他新功能
- 不改变右键菜单、日期选择器等现有交互
