# 视觉一致性与可达性打磨（codex 批次）

## 用户故事

作为一名每天在谨迹里浏览技能 / 想法 / 自动化等多个 Hub 页的知识工作者，
我希望主操作按钮长相一致、副文本看得清、空状态安静不抢眼，
以便我「打开即平静」，一眼分辨「该点哪」「现在什么状态」，而不被半成品感与视觉噪声打断阅读。

## 背景与失败模式

[证据] 三个同级主操作按钮三种长相：`技能` 页「新建技能」是填充浅珊瑚/粉（`apps/web/src/styles/globals.css` 内 skills primary 按钮样式），`想法`「新建想法」、`自动化`「新建自动化」是深色 ghost。违背 DESIGN.md「单一信号橙 `#FF5701` 是所有 accent 唯一来源」。
[证据] 暗色主题 `--text-tertiary: #6b7280`、`--text-secondary: #a2a6ae`（globals.css:472-473）在近黑底上对比偏低，「上次成功」「/斜杠命令」等关键/提示文本最弱。
[证据] `专题 / 核心画像 / Timeline` 空状态铺超大「谨迹」字形水印，亮度/尺寸过高，在 Timeline 上与「粘贴/拖文件」区抢焦点。

## 成功标准（GWT 验收）

- **AC-1**（按钮 accent 统一）Given 用户停留在 `技能` / `想法` / `自动化` 任一 Hub 页，When 观察其主操作（新建*）按钮，Then 三者均为实心 `var(--accent)`（#FF5701）背景 + 白色文字、同一圆角 token，无浅珊瑚/粉填充残留。
- **AC-2**（对比度达标）Given 暗色主题下渲染正文副文本（secondary）与元信息/提示文本（tertiary/muted），When 用对比度工具测量文字色与其所在表面背景色，Then secondary ≥ 4.5:1、tertiary/muted ≥ 3:1（WCAG AA）；附测量数值。
- **AC-3**（水印收敛）Given 用户进入 `专题` / `核心画像` / `Timeline` 的空状态，When 观察背景「谨迹」水印，Then 水印不透明度 ≤ 0.04（或等效极淡），不再与中央引导区（「粘贴/拖文件」「在左侧选择…」）争夺视觉焦点；引导区成为唯一焦点。

## 边界（Won't）

- **不为谁**：不改动按钮的交互行为、点击逻辑、文案。
- **不做哪些场景**：不动浅色主题中已达标的 token（仅在低于阈值时上调）；不重构按钮组件 API；不替换水印图形本身（只调不透明度/尺寸）。
- **不解决**：不在本批次处理页眉统一（G3）、统计卡去冗余（G4）等需产品决策项。

## 交棒 design（实现层）

- 按钮统一应抽到结构化 token / 复用现有 primary 按钮类，避免各页硬编码（DESIGN.md §5）。
- 对比度调整须验证真实渲染链（CLAUDE.md 约束7：`.md-content` / 各页 CSS cascade），computed style 为准，非源码值。
