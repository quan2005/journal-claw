# 全屏工作区隐藏左侧边栏及展开/收起按钮

> 一句话概括：**全局删除左侧边栏的展开/收起按钮，保留右侧边栏按钮；在“想法”“自动化”“技能”三个全屏工作区完全隐藏左侧树形边栏容器。**

## 用户故事（Connextra）

作为 **频繁使用 JournalClaw 整理日志、想法、自动化和技能配置的知识工作者**，
当我 **在任意页面浏览或操作时**，
我希望 **左侧边栏的展开/收起按钮不再出现；在“想法”“自动化”“技能”工作区，左侧树形边栏容器也完全隐藏；右侧边栏按钮保留，以保证 Agent 面板可正常打开**，
以便 **界面更简洁、专注于内容，同时右侧 Agent 引擎仍然可用**。

## 真实用户问题（背景，讲故事）

当前应用始终渲染左侧边栏容器和 divider 上的展开/收起按钮，不受当前页面类型影响。切换到“想法”“自动化”“技能”时，虽然边栏内部为空且默认收起，但按钮和容器仍然可见，形成视觉噪音并暗示存在可展开的侧边内容，与实际设计意图不符。同时，在“流水”“画像”“专题”等需要树形导航的页面，展开/收起按钮也造成了不必要的控件冗余。

### 现状失败模式

- 用户在“想法”页面看到左侧有一个可点击的 `<` / `>` 按钮，但点击后展开的是空边栏。
- 在“流水”“画像”“专题”页面，展开/收起按钮提供了收起边栏的功能，但用户认为该控件不再必要，希望边栏保持固定显示。
- 按钮和 divider 占据了左侧空间，与“全屏工作区”的视觉定位冲突。

**证据**：
- `apps/web/src/App.tsx` 始终渲染 `app-sidebar-panel` 和 divider 按钮，不受 `activeCategory` 影响。
- `apps/web/src/App.tsx` 的 `handleCategoryChange` 已识别 `needsSidebar = cat === 'journal' || cat === 'identity' || cat === 'topics'`，非 sidebar 类别会自动收起，但未移除容器。
- `apps/web/src/components/TreeSidebar.tsx` 在 ideas/automation/skills 状态下不渲染树内容。
- `NavRail.tsx` 中 `FULLSCREEN_ITEMS` 已把 ideas/automation/skills 标记为全屏工作区。

## 成功标准（脊柱 Q4）

### 用户行为变化

做完后，用户会：
- 在任意页面都看不到左侧边栏的展开/收起按钮（基线：按钮始终可见；目标：按钮完全移除）。
- 右侧边栏的展开/收起按钮保留，用户仍可方便打开/关闭右侧 Agent 面板（基线：按钮始终可见；目标：继续保留）。
- 在“想法”“自动化”“技能”三个工作区，左侧树形边栏容器完全隐藏，内容区域占满可用宽度（基线：容器存在但收起；目标：容器不渲染）。
- 在“流水”“画像”“专题”页面，左侧树形边栏仍可通过点击最左侧导航 Rail 的当前分类按钮来收起/展开（基线：通过 divider 上的按钮切换；目标：通过 NavRail 当前分类按钮切换）。

⚠️ 假设依据：以上基于用户直接反馈（截图 + 文字说明），属于直觉/定性反馈。可通过后续用户观察确认是否减少误点击。

## 验收标准（Given-When-Then）

### AC-1 — 想法页面无左侧边栏
- **Given** 用户当前处于“想法”工作区
- **When** 页面渲染完成
- **Then** 左侧不显示树形边栏容器
- **And** 左侧不显示展开/收起按钮

### AC-2 — 自动化页面无左侧边栏
- **Given** 用户当前处于“自动化”工作区
- **When** 页面渲染完成
- **Then** 左侧不显示树形边栏容器
- **And** 左侧不显示展开/收起按钮

### AC-3 — 技能页面无左侧边栏
- **Given** 用户当前处于“技能”工作区
- **When** 页面渲染完成
- **Then** 左侧不显示树形边栏容器
- **And** 左侧不显示展开/收起按钮

### AC-4 — 所有页面删除左侧展开/收起按钮
- **Given** 用户当前处于任意工作区
- **When** 页面渲染完成
- **Then** 左侧不显示展开/收起按钮

### AC-5 — 需要侧边栏的页面仍显示边栏容器
- **Given** 用户当前处于“流水”“画像”或“专题”工作区
- **When** 页面渲染完成
- **Then** 左侧仍显示树形边栏容器
- **And** 边栏默认处于展开状态

### AC-6 — 通过 NavRail 切换边栏展开/收起
- **Given** 用户当前处于“流水”“画像”或“专题”工作区
- **When** 用户点击最左侧导航 Rail 上当前已激活的分类按钮
- **Then** 左侧树形边栏在展开与收起之间切换
- **And** 切换过程中不显示独立的展开/收起按钮

### AC-7 — 右侧边栏按钮保留且可切换面板
- **Given** 用户当前处于任意工作区
- **When** 页面渲染完成
- **Then** 右侧 divider 上仍显示展开/收起按钮
- **And** 点击该按钮可切换右侧 Agent 面板的打开/关闭状态

## 三类边界（脊柱 Q5 · Won't · 输出闸必填）

- **不为哪些用户做**：不特别为需要频繁收起/展开左侧边栏的用户保留按钮；本次调整按用户要求全局移除按钮。
- **不在哪些场景出现**：不在“流水”“画像”“专题”等需要树形导航的页面隐藏边栏容器；不删除右侧聊天/对话面板的展开/收起按钮；不影响底部面板或导航 Rail（NavRail）。
- **不解决哪些相关但不同的问题**：不重新设计整体布局架构；不改动 TreeSidebar 组件内部逻辑；不引入新的拖拽调整边栏宽度功能；不涉及 localStorage 中侧边栏宽度的持久化策略清理；不调整响应式断点行为（<720px 强制收起等），但相关逻辑可能因按钮移除而失效，需由 design.md 决定是否同步清理。
