# 精简工作区空态与面板分隔控件

> 一句话概括：**为在三栏工作区浏览日志、沉浸阅读并与 Agent 对话的知识工作者，移除干扰主任务的冗余入口，并以产品自身称谓呈现空会话。**

## 用户故事（Connextra）

作为 **在本地工作区浏览日志、阅读详情并与 Agent 对话的知识工作者**，
当我 **进入主工作区但尚未选择日志，或打开一个没有消息的新会话**，
我希望 **界面只保留与当前主任务直接相关的内容，并使用产品自身称谓**，
以便 **不用辨认无关按钮或个人化占位文案，就能继续阅读或开始对话**。

## 真实用户问题（背景，讲故事）

[证据] 用户在 2026-07-30 提供真实界面截图，明确圈出左右面板分隔线上的两个折叠按钮和中央“粘贴 / 拖文件”卡片，要求删除；随后明确要求把右侧空会话的“闫戍's momo”改为“您的谨迹”。

[证据] `stories/20260701-hide-sidebar-for-fullscreen-workspaces/story.md` 曾要求删除左侧折叠按钮，但当前界面再次出现该按钮，属于已验收行为的回归候选。该历史契约保留了右侧按钮，因此本次删除右侧按钮仍是新的产品范围。

[证据] `docs/final-state.md` 将高效浏览、沉浸阅读和右侧 Agent 面板定义为核心体验；本次只精简这些核心界面上的冗余可见入口，不下线底层能力。

### 现状失败模式

- 用户现在只能忽略三个不需要的可见入口，并自行判断它们是否与当前任务有关。
- 左右折叠箭头占据两条面板分隔线，中央大卡片又在未选中日志时成为主要视觉焦点；同屏需过滤的非目标入口为 3 个。
- 空会话使用个人名和英文所有格“闫戍's momo”，没有以产品和当前用户的关系表达助手归属。

## 成功标准（脊柱 Q4）

### 用户行为变化

做完后，目标用户会：

- 进入主工作区后，无需辨认或绕开截图所示入口：同屏需过滤的非目标入口从 **3 个降为 0 个**。
- 打开空会话后直接看到产品归属文案：目标文案“您的谨迹”从 **0 处变为 1 处**，旧文案从 **1 处降为 0 处**。
- 继续使用已有替代路径完成面板唤起和文件导入：已保留的快捷键、业务触发与全窗口拖放路径可用率保持 **100%**。

⚠️ 假设依据：以上基于用户提供的真实截图与明确文字指令；通过自动化回归测试和真实渲染 smoke 验证。

## 验收标准（Given-When-Then）

### AC-1 — 分隔线不再显示折叠按钮

- **Given** 用户进入会显示左侧日志栏、中间详情区和右侧对话区的主工作区
- **When** 界面完成渲染
- **Then** 左右面板分隔线上均不显示折叠或展开按钮
- **And** 分隔线本身及三栏布局仍存在

### AC-2 — 日志未选中态不再显示粘贴卡片

- **Given** 工作区已有日志且用户尚未选择任何日志
- **When** 中央详情区显示未选中状态
- **Then** 不显示“粘贴 / 拖文件”卡片
- **And** 不显示失去对应选项的“通过以下方式开始记录”孤立标题

### AC-3 — 空工作区仍有示例入口

- **Given** 工作区没有任何日志
- **When** 中央详情区显示首次使用空状态
- **Then** 用户仍能看到并使用“创建示例条目”
- **And** 不显示“粘贴 / 拖文件”卡片

### AC-4 — 空会话使用产品称谓

- **Given** 右侧对话区没有消息、排队内容或生成中的回复
- **When** 空会话提示出现
- **Then** 提示文字精确显示为“您的谨迹”
- **And** 页面中不再出现“闫戍's momo”

### AC-5 — 替代交互保持可用

- **Given** 可见的分隔线按钮和中央粘贴卡片已移除
- **When** 用户通过既有快捷键或业务入口唤起对话区，或向桌面窗口拖入受支持文件
- **Then** 对话区仍能按既有规则开合，文件仍能进入既有导入流程
- **And** 用户仍可拖动已展开面板的分隔线调整宽度

## 三类边界（脊柱 Q5 · Won't · 输出闸必填）

- **不为哪些用户做**：不为只使用 daemon/API、看不到图形工作区的集成用户增加任何行为；本故事只服务主工作区的知识工作者。
- **不在哪些场景出现**：不删除文件树节点的展开/折叠控件、设置页返回按钮、标题栏控件、聊天工具栏按钮或其他未被截图圈出的交互。
- **不解决哪些相关但不同的问题**：不下线面板状态、快捷键、响应式自动收起、面板宽度拖拽/持久化、全窗口文件拖放、文件导入、示例条目创建或对话能力；不重构三栏布局。

## 交棒清单（移交 design.md 的实现层问题）

- [x] 兼容性：移除可见按钮后必须保留现有快捷键、业务唤起、响应式状态与分隔线拖拽。
- [x] 可靠性：移除“粘贴 / 拖文件”卡片不得触碰 Electron host file-drop 链路。
- [x] 受影响的相邻模块：App 面板 shell、DetailView 未选中态、WorkspaceChatShell 空会话、对应组件测试。
